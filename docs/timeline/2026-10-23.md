# Learning Timeline — 2026-10-23

- [AtCoder AALC001 D](../../src/atcoders/contest/aalc001/d/): With values in `{0,1,2}`, a segment stores the three counts and its inversion count; across the midpoint only a left `2` with a right `0` or `1`, and a left `1` with a right `0`, create new inversions.
- [AtCoder AALC001 E](../../src/atcoders/contest/aalc001/e/): Each color keeps its weight sum, plus the already-paired `RG` and `GB` products; a triple crosses the midpoint only as left `RG` times a right `B`, or a left `R` times right `GB`.
- [AtCoder AALC001 F](../../src/atcoders/contest/aalc001/f/): A run sits in one child or crosses as the left equal suffix plus the right equal prefix when the touching values match; the prefix and suffix grow only when that whole child is one value.
- [AtCoder AALC001 H](../../src/atcoders/contest/aalc001/h/): Nonnegative additions make every earlier mod collapse into the rightmost zero, so a sum Fenwick plus a zero-count Fenwick answers `(x + sum through that zero) mod 998244353`, then adds the tail.
- [Codeforces 19A](../../src/codeforces/set0/set0/set010/set019/a/): Award 3/1/0, order by points, goal difference, then goals, and emit the leading half of the table in lexicographic order.
- [Codeforces 24A](../../src/codeforces/set0/set0/set020/set024/a/): A ring becomes strongly connected only as one of the two directed cycles, so the cost is the cheaper set of edges that point against the chosen orientation.
- [Codeforces 30A](../../src/codeforces/set0/set0/set030/set030/a/): Reduce `A·X^n = B` to an integer nth root of `|B|/|A|`, reject an even power of a negative ratio, and abort the power once it passes the target.
- [Codeforces 38C](../../src/codeforces/set0/set0/set030/set038/c/): For every strip height `d ≥ l`, each board contributes `floor(a_i / d)` strips and the area is `d` times that total.
- [Codeforces 42A](../../src/codeforces/set0/set0/set040/set042/a/): The largest scale is the minimum of every `b_i / a_i` and of `V / sum(a)`; the cooked volume is that scale times `sum(a)`.
- [Codeforces 60B](../../src/codeforces/set0/set0/set060/set060/b/): BFS through `.` cells on each floor and through the same cell on the floors immediately above and below.
- [Codeforces 75E](../../src/codeforces/set0/set0/set070/set075/e/): Clip the segment with the island's inward half-planes; a chord on one edge stays sea-priced, and a real interior chord is replaced by `min(2|AB|, the shorter shore)`.
- [Codeforces 77A](../../src/codeforces/set0/set0/set070/set077/a/): Every split of 7 heroes into three nonempty sizes has experience gap `max(monster/size) - min(monster/size)`; among minimum-gap splits, permute the heroes to maximize likes inside teams.
- [Codeforces 79B](../../src/codeforces/set0/set0/set070/set079/b/): Sweep wastes and queries in row-major order; a cultivated cell's crop is `(row * m + column - wastes before it) mod 3`.
- [Codeforces 81A](../../src/codeforces/set0/set0/set080/set081/a/): A stack deletes a pair as soon as the new letter matches the top, which is the same as repeatedly removing consecutive duplicates.
- [Codeforces 120E](../../src/codeforces/set0/set1/set120/set120/e/): Optimal knight placement is settled by parity: the first player wins exactly when the board side is odd.
- [Codeforces 120F](../../src/codeforces/set0/set1/set120/set120/f/): One DFS keeps the two longest downward chains, so each spider contributes its edge-diameter, and gluing them end to end sums those diameters.
- [Codeforces 124B](../../src/codeforces/set0/set1/set120/set124/b/): `k ≤ 8`, so every shared digit permutation is tried and the answer is the smallest max-minus-min among the rearranged numbers.
- [Codeforces 180C](../../src/codeforces/set0/set1/set180/set180/c/): One cut leaves an uppercase prefix and a lowercase suffix; the cost is the lowercase letters on the left plus the uppercase letters on the right, tracked with two running counts.
- [Codeforces 435C](../../src/codeforces/set0/set4/set430/set435/c/): Alternating segments move diagonally up and down; the grid is `sum(a)` wide and `high - low` tall, and each segment paints `/` or `\`.
- [Codeforces 699B](../../src/codeforces/set0/set6/set690/set699/b/): Cell `(i, j)` clears every wall when `row[i] + col[j]`, minus one if the cell itself is a wall, equals the number of walls.
- [Codeforces 710B](../../src/codeforces/set0/set7/set710/set710/b/): On a line the sum of distances is minimized on the median, and the lower median is the leftmost optimal point when the count is even.
- [Codeforces 1196B](../../src/codeforces/set1/set11/set119/set1196/b/): A segment sum is odd exactly at an odd element. At least `k` odds are required, the surplus must be even, and the cuts fall after the first `k - 1` odds.
- [Codeforces 1384A](../../src/codeforces/set1/set13/set138/set1384/a/): Each next string copies the previous one and flips the character at index `a_i`, with the length raised to the neighboring prefix demands.
- [Codeforces 2161C](../../src/codeforces/set2/set21/set216/set2161/c/): Because every price is at most `X`, a purchase scores only when it wraps the running sum. Buy the largest item when it wraps, and the smallest item when it does not.
- [Codeforces 2192B](../../src/codeforces/set2/set21/set219/set2192/b/): Flipping everyone except `i` means the chosen set is either every `1`, which works when that count is even, or every `0`, which works when that count is odd.
- [Codeforces 2200D](../../src/codeforces/set2/set22/set220/set2200/d/): Rotate the open interval between the portals so its minimum is first, then splice that block into the outside sequence before the first outside value larger than the minimum.
- [Codeforces 2218E](../../src/codeforces/set2/set22/set221/set2218/e/): The answer is the maximum XOR of any two elements, found by comparing every pair.
- [Codeforces 2224B](../../src/codeforces/set2/set22/set222/set2224/b/): Place the global maximum first so every prefix maximum is `mx`, then let the prefix MEX climb `0, 1, …, mex - 1` and stay at `mex`; the closed form shortens that plateau when `0..mx` are all present.
- [Codeforces 2233C](../../src/codeforces/set2/set22/set223/set2233/c/): The longest regular subsequence is twice the greedy left-to-right matching. Spend all `k` deletions on a prefix of `(` and a suffix of `)`, and keep the split with the smaller matching.
- [Codeforces 2259G](../../src/codeforces/set2/set22/set225/set2259/g/): `a[i] - i·k` turns a good array into a non-increasing one. Deleting `i` pulls the following elements onto the staircase `a[i-1] + k, +2k, …`, and a monotone pointer sums the surplus above that line.
- [Codeforces 2260C](../../src/codeforces/set2/set22/set226/set2260/c/): `x + y` is invariant and is the maximum XOR. The fewest steps are the difference between `x` and `x + y` on the bits below the highest bit set in `x` but missing from the sum.
- [Codeforces 2266C](../../src/codeforces/set2/set22/set226/set2266/c/): A sorted binary string is zeros followed by ones. A leading one means every zero must be raised; a leading zero pays for the ones before the cut plus the zeros after it.
- [Gym 105161E](../../src/gym/set105161/e/): Halving `v` down below `x` takes `bits.Len(v / x)` steps. Parallel binary search stores, in a Fenwick tree, the extra halvings between `high` and `mid`, and sends a query left only after it pays that cost.
- [Luogu P2448](../../src/luogu/set2/p2448/): Compress the touched days, simulate the swaps, count inversions among them with a Fenwick tree, and charge each displaced value for the untouched integers strictly between its origin and its destination.
- [Luogu P2617](../../src/luogu/set2/p2617/): Whole binary search on the compressed values. An insertion and a deletion are Fenwick deltas `+1` and `-1`; a query goes left when that half already contains `k` values, and subtracts the count on the way right.
- [Luogu P3188](../../src/luogu/set3/p3188/): Group weights `a·2^b` by the trailing power of two, knapsack each coefficient, then merge the groups bit by bit into the residual capacity of `W`. The answer is the top bit with one high unit.
- [Luogu P3250](../../src/luogu/set3/p3250/): Binary-search the importance. A path is marked on the Euler tour at both ends and subtracted at the LCA and its parent, so a server still has an avoiding request when its subtree cover is below the number of live paths.
- [Luogu P3332](../../src/luogu/set3/p3332/): Binary-search from the large side. A segment tree range-adds one for every insertion at least the midpoint, and a query that already sees `k` such values stays with the larger half.
- [Luogu P3514](../../src/luogu/set3/p3514/): The best even and odd fragment sums are a prefix or a suffix of the whole stick. From each, dropping a `T`, or both end `W`s, fills every smaller positive sum of the same parity.
- [Luogu P3834](../../src/luogu/set3/p3834/): Offline divide-and-conquer on value: a Fenwick tree counts how many positions of the small half lie in the query, and the query keeps the small half only when that count is at least `k`.
- [Luogu P4093](../../src/luogu/set4/p4093/): Each index keeps the min and max of its original value and its modifications. CDQ on index order extends a left state to the right when the left max is at most the right original value, using a Fenwick prefix maximum up to the right minimum.
- [Luogu P5329](../../src/luogu/set5/p5329/): Two deletions differ at the first character after the equal run containing the earlier index. Deletions inside the same run leave identical strings, so the smaller index comes first.
- [Luogu P5677](../../src/luogu/set5/p5677/): Pair each value with its closest neighbor on the sorted line, including both neighbors on a tie. Insert the pair at its left index once the right index is reached, and a Fenwick range sum is the pairs inside a query.
- [Luogu P9588](../../src/luogu/set9/p9588/): Each append is the block `1..x`. A global popped count walks whole blocks off the front; the `z`-th living element is the offset in the block whose prefix sum covers it, and a segment tree keeps each block's maximum until the block is fully consumed.
