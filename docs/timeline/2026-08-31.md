# Learning Timeline — 2026-08-31

- [Codeforces 2127C](../../src/codeforces/set2/set21/set212/set2127/c/): Pairs become intervals `[min,max]`; after a left-endpoint sort, any neighbor overlap keeps the initial length-sum, otherwise Bahamin adds twice the smallest adjacent gap and one round suffices.
- [Codeforces 2151C](../../src/codeforces/set2/set21/set215/set2151/c/): Max stay is the area under the densest valid occupancy; `k=1,2` seed odd/even gap weights, then `ans_k = ans_{k-2} + 2·(pref[2n-k+1]-pref[k-2])`.
- [Codeforces 2152C](../../src/codeforces/set2/set21/set215/set2152/c/): A window is emptyable iff length and ones-count are multiples of 3; cost is `len/3`, plus one when an alternating-run prefix shows the whole range is `01…`/`10…`.
- [Codeforces 2244C](../../src/codeforces/set2/set22/set224/set2244/c/): Swaps of distances `x,y` mix each residue class modulo `gcd(x,y)`; sort values onto sorted positions inside every class and accept iff the rebuilt array is increasing.
