# F. Spiders

[题目链接](https://codeforces.com/problemset/problem/120/F)

**比赛：** [School Regional Team Contest, Saratov, 2011](https://codeforces.com/contest/120)

**标签：** dp, greedy, trees, \*1400

time limit per test: 1 second

memory limit per test: 256 megabytes

input: input.txt

output: output.txt

## 题意

一天，妈妈让 Petya 整理玩具并扔掉一些。Petya 发现一整盒玩具蜘蛛，舍不得扔。他打算把所有蜘蛛粘在一起，再挂到天花板上：挂得越低，妈妈越喜欢，就越不会扔掉这些玩具。请帮助他完成这个计划。

一只蜘蛛由 `k` 颗珠子和 `k - 1` 根线组成。每根线连接两颗不同的珠子；任意两颗珠子要么直接相连，要么通过一串线和珠子相连（也就是一棵树）。

Petya 可以把蜘蛛直接粘在一起：把某些珠子粘成同一颗（珠子大小可忽略，每根线长度为 1）。粘合之后的结构仍然必须是一只蜘蛛，即仍满足上面的性质。

全部粘好后，定义两颗珠子的距离为连接它们的线的总长度，成品的长度是所有珠子对之间的最大距离。Petya 希望这个长度尽可能大。

题目图示（第二组样例）：可以把第一只蜘蛛的 2 号珠子与第二只蜘蛛的 1 号珠子粘在一起；图中高亮的是构成最大长度的那条线的序列。

## 约束

- 单组数据
- 蜘蛛数量 `n`（`1 ≤ n ≤ 100`）
- 第 `i` 只蜘蛛有 `n_i` 颗珠子（`2 ≤ n_i ≤ 100`），编号从 `1` 到 `n_i`
- 每只蜘蛛给出 `n_i - 1` 条边

## 输入

第一行一个整数 `n` — 蜘蛛数量。

接下来 `n` 行，每行描述一只蜘蛛：先是整数 `n_i`，然后是 `n_i - 1` 对整数，表示被线连接的两颗珠子的编号。

## 输出

输出一个整数 — 所能得到的成品的最大长度。

## 样例

### 样例 1

输入

```
1
3 1 2 2 3
```

输出

```
2
```

### 样例 2

输入

```
2
3 1 2 1 3
4 1 2 2 3 2 4
```

输出

```
4
```

### 样例 3

输入

```
2
5 1 2 2 3 3 4 3 5
7 3 4 1 2 2 4 4 6 2 7 6 5
```

输出

```
7
```
