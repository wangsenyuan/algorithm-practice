## Problem: Given Length and Sum of Digits...

Vasya has an integer of length `m` and digit sum `s`. Help him find the lexicographically smallest and largest decimal integers with exactly `m` digits and digit sum `s`. Numbers must not contain leading zeroes.

### Input

The first line contains two integers `m` and `s` (`1 <= m <= 100`, `0 <= s <= 900`) — the length and digit sum.

### Output

Print the smallest and largest numbers separated by a space. If no such number exists, print `-1 -1`.

### Examples

```text
Input
2 15

Output
69 96
```

```text
Input
3 0

Output
-1 -1
```
