# Learning Timeline — 2026-07-31

- [AtCoder ABC327 D](../../src/atcoders/abc/abc300/abc320/abc327/d/): Constraints `X_S ≠ X_T` are undirected edges on `1..N`, so the pair is good exactly when that graph is bipartite (self-loops fail immediately).
- [AtCoder ABC327 E](../../src/atcoders/abc/abc300/abc320/abc327/e/): For each chosen count `k`, an in-order DP maintains the best `0.9`-weighted average of performances, then subtracts `1200/√k` and takes the maximum over `k`.
- [AtCoder ABC327 F](../../src/atcoders/abc/abc300/abc320/abc327/f/): A fixed `D×W` basket is a time sweep of active apples, each contributing `+1` on compressed left endpoints `[X-W+1, X]`; a lazy range-add / range-max segment tree tracks the peak occupancy.
- [AtCoder ABC327 G](../../src/atcoders/abc/abc300/abc320/abc327/g/): Counting length-`M` good pairs reduces to bipartite multigraph enumeration: two-colored graphs → connected via component subtraction → set-partitions of components → bundles over simple edges, then modular powering for large `M`.
- [Codeforces 1089K](../../src/codeforces/set1/set10/set108/set1089/k/): Each knight is a finish-time map `F(x)=max(x+sum, fixed)` whose merge is associative, so a segment tree on arrival time answers wait queries as `max(0, fixed-t)` on the prefix through `t`.
- [Codeforces 2228C2](../../src/codeforces/set2/set22/set222/set2228/c2/): Closest `d`-digit number to `a` is built by matching a shared prefix, branching to the nearest lower/upper allowed digit with min/max fills, and also trying one shorter and one longer candidate.
- [Codeforces 2229D](../../src/codeforces/set2/set22/set222/set2229/d/): Binary-searching the target `w` maps each column to how many of `{a_i,b_i}` are `≥ w`; after dropping singleton columns, feasibility is whether runs of “both” outnumber runs of “neither”.
- [Codeforces 2230D](../../src/codeforces/set2/set22/set223/set2230/d/): A right-to-left scan stores next occurrences of each episode and chains through equal next-episode positions, so each left endpoint contributes how far the spoiler-free window can extend.
- [Codeforces 2236G](../../src/codeforces/set2/set22/set223/set2236/g/): Nonnegative `XOR ≥ sum` means no repeated bits; root-path forbidden starts plus LCA split reduce each query to counting disjoint-mask pairs across two short nonzero arms.
