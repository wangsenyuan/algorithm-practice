# 1196B — Odd Sum Segments

Given an array of `n` positive integers, split it into exactly `k` nonempty consecutive segments, each with an odd sum. Print `NO` if this is impossible. Otherwise print `YES` and the one-based right endpoint of every segment; the last endpoint must be `n`.

The input begins with `q` independent queries. Each query contains `n k` followed by the `n` array elements. The sum of `n` across queries is at most 200,000.
