# 1933D — Turtle Tenacity: Continual Mods

Given an array of positive integers, determine whether its elements can be rearranged so that applying modulo from left to right produces a nonzero result. For each test case, output `YES` or `NO`.

The input starts with the number of test cases `t`. Each case contains `n` (`2 ≤ n ≤ 10^5`) and `n` integers (`1 ≤ a_i ≤ 10^9`). The sum of `n` over all cases is at most `2 × 10^5`.
