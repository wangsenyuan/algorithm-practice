# Learning Timeline — 2026-07-28

- [Codeforces 98B](../../src/codeforces/set0/set0/set090/set098/b/): Knuth–Yao free-node states give `E[k] = 1 + (r/(2k))E[r]` with `r = (2k) mod n`; walking only the orbit of `1` and closing the cycle with `E[c0] = (Σ c[j]·2^{L-j}) / (c[0]·(2^L-1))` avoids slow rational chaining on long doubling cycles.
- [Codeforces 257C](../../src/codeforces/set0/set2/set250/set257/c/): Sorting polar angles from `atan2` makes the minimum origin-centered cover equal to a full turn minus the largest empty consecutive gap (including wrap-around), so collinear same-ray points correctly yield angle `0`.
- [Codeforces 261B](../../src/codeforces/set0/set2/set260/set261/b/): Expected seated guests is `Σ_k Pr(X ≥ k)`, and `Pr(X ≥ k)` is just the fraction of `k`-subsets with sum `≤ p`, so one 0-1 knapsack plus `ways(k)/C(n,k)` replaces blocker counting and big factorials.
- [Codeforces 266C](../../src/codeforces/set0/set2/set260/set266/c/): Peeling size `n` downward, swap to clear column `n` of ones then bring a nonempty last row into place so remaining ones sit strictly below the diagonal, then recurse on the leading `(n-1)×(n-1)` block.
- [Codeforces 2238C](../../src/codeforces/set2/set22/set223/set2238/c/): Distinct subtree distance-layers equal `n` singletons plus, at each node with at least two children, `best2 + 1` new multi-branch guilds limited by the second-tallest child height.
- [Codeforces 2239B](../../src/codeforces/set2/set22/set223/set2239/b/): Circle FOV happiness expands to `Σ s_i(2d·a_i - A_i)` with no cross terms, so each seat is taken independently when `2d·a_i > A_i`, and doubled prefix sums evaluate every neighbor sum in linear time.
