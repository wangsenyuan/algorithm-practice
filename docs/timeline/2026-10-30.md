# Learning Timeline — 2026-10-30

- [AtCoder AALC001 G](../../src/atcoders/contest/aalc001/g/): A node stores the power sums through the fourth. Adding `x` rewrites them from the high power downward, since each `(a+x)^k` expands into the sums already stored.
- [AtCoder AALC001 I](../../src/atcoders/contest/aalc001/i/): Besides the best one-segment and two-segment sums, a node keeps the best that touches the left end, the right end, or both. A segment that crosses the midpoint is a left suffix plus a right prefix, and the other segment has to sit outside that block.
- [AtCoder AALC001 J](../../src/atcoders/contest/aalc001/j/): Compress the query endpoints and store, on each atomic segment, how many ones it holds. A flip replaces that count by the segment length minus the count, and the lazy tag is a toggle.
- [AtCoder AALC001 K](../../src/atcoders/contest/aalc001/k/): One Fenwick tree counts occurrences and another stores their sum. With `cnt` elements at most `x` and `tail` the sum of everything larger, an insertion adds `(cnt+1)·x + tail` and a deletion subtracts `cnt·x + tail`, because only the larger ranks move.
- [AtCoder AALC001 L](../../src/atcoders/contest/aalc001/l/): Each node keeps the sum and the maximum prefix of all three arrays, and the lazy tag is a permutation of those three slots. The swaps are transpositions, so a new tag composes as `lazy[perm[i]]` rather than a shared rotation. The query walks to the first prefix of `A` whose sum is positive.
- [AtCoder AALC001 M](../../src/atcoders/contest/aalc001/m/): NAND separates by bit. A node maps an incoming bit to the outgoing one: `0` becomes `1`, and `1` becomes the opposite of this position's bit. The range is composed left to right and each result bit is shifted back into place.
- [Codeforces 359B](../../src/codeforces/set0/set3/set350/set359/b/): Because `2k ≤ n`, the first `k` pairs differ by `-1` and the rest by `+1`. The absolute sum is `n` and the signed sum is `2k-n`, so the expression equals `2k`.
- [Codeforces 360C](../../src/codeforces/set0/set3/set360/set360/c/): A greater character at `i`, after the previous mismatch at `p`, adds `(i-p)·(n-i+1)`. Smaller characters add nothing and collapse into a prefix sum; a greater one only needs lengths `L ≤ j/(n-i+1)`.
