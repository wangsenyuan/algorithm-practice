# Learning Timeline — 2026-07-24

- [AtCoder ABC426 C](../../src/atcoders/abc/abc400/abc420/abc426/c/): A queue of still-relevant version numbers and per-version PC counts lets each old version be consumed once and merged into its upgrade target, giving `O(N + Q)` processing.
- [AtCoder ABC426 D](../../src/atcoders/abc/abc400/abc420/abc426/d/): Leaving one maximal equal-bit run untouched turns every opposite bit outside it into a one-move cost and every matching bit outside it into a two-move cost; suffix counts evaluate all runs in linear time.
- [AtCoder ABC426 E](../../src/atcoders/abc/abc400/abc420/abc426/e/): The relative-position distance is convex while both walkers move and again after the first walker stops, so splitting at the earlier arrival time makes two independent ternary searches valid.
- [AtCoder ABC426 F](../../src/atcoders/abc/abc400/abc420/abc426/f/): A lazy segment tree tracks each segment's minimum active stock and active-product count, subtracting an order wholesale when possible and descending only to products that sell out; each product incurs that extra work once.
- [AtCoder ABC426 G](../../src/atcoders/abc/abc400/abc420/abc426/g/): Offline divide and conquer assigns each range query to its first crossed midpoint, builds left/right knapsack tables around that split, and combines them over every capacity partition in `O(K(N log N + Q))`.
- [Codeforces 212D](../../src/codeforces/set0/set2/set210/set212/d/): Asymmetric monotonic-stack boundaries assign every subarray minimum to one index; each index contributes a trapezoid over window lengths whose four slope changes reconstruct all length sums in `O(N + M)`.
- [Codeforces 493D](../../src/codeforces/set0/set4/set490/set493/d/): The chess game collapses to board-size parity: odd `n` is winning for black, while even `n` is winning for white with the lexicographically smallest first move `(1, 2)`.
- [Codeforces 513D1](../../src/codeforces/set0/set5/set510/set513/d1/): Fixed preorder labels make every subtree a contiguous interval; LEFT/RIGHT constraints become bounds on its split point, enabling memoized interval construction and inorder reconstruction in `O(N^3 + C)`.
- [Codeforces 513D2](../../src/codeforces/set0/set5/set510/set513/d2/): Compressing each root's constraints to extreme required labels supports a greedy shortest-left-subtree construction; explicit build and traversal stacks scale the same interval invariant to `O(N + C)`.
- [Codeforces 742B](../../src/codeforces/set0/set7/set740/set742/b/): Scanning left to right, each value `v` pairs with exactly the previously seen occurrences of `v XOR x`, so one frequency map counts every valid index pair once in linear time.
- [Codeforces 1090L](../../src/codeforces/set1/set10/set109/set1090/l/): For a candidate `w`, usable attendance is the sum of `min(capacity, w)` over odd and even lectures; this monotone feasibility test binary-searches the maximum passing students over `[0, t]`.
- [Codeforces 2181F](../../src/codeforces/set2/set21/set218/set2181/f/): The implemented game-state reduction counts every size-one pile plus one additional token if any larger pile exists; Alice wins exactly when that reduced count is odd.
- [Codeforces 2241F](../../src/codeforces/set2/set22/set224/set2241/f/): After trimming leading zeroes and trailing ones that cannot form inversions, the position is winning exactly when the active middle contains an odd-length equal-bit run, yielding an `O(N)` scan.
