# Learning Timeline — 2026-07-29

- [Codeforces 223C](../../src/codeforces/set0/set2/set220/set223/c/): `k` iterated prefix sums compose to binomial weights `C(k-1+d,d)`, so precomputing those coefficients by the modular recurrence `C[d+1]=C[d]·(k+d)/(d+1)` turns a huge `k` into an `O(n^2)` convolution.
- [Codeforces 225E](../../src/codeforces/set0/set2/set220/set225/e/): Values that cannot appear as `⌊x/2⌋+y+xy` are exactly `2^{p-1}-1` for Mersenne-prime exponents `p`, so `z_n` is a table lookup plus modular powering.
- [Codeforces 813F](../../src/codeforces/set0/set8/set810/set813/f/): Edge toggles become active time intervals stored on a segment tree; a parity DSU with rollback answers bipartiteness at each leaf in `O(q log q log n)` without online deletions.
- [Codeforces 926I](../../src/codeforces/set0/set9/set920/set926/i/): Sorting alarm minutes on a 24-hour circle, the longest sleep is one less than the maximum gap between consecutive alarms (including wrap-around).
- [Codeforces 2232C2](../../src/codeforces/set2/set22/set223/set2232/c2/): Seat introverts on fresh tables eagerly, fill non-empty tables preferentially for `A`/`E`, and when an extrovert needs a starter, relocate a previously free ambivert to open a new non-empty table.
- [Codeforces 2238E](../../src/codeforces/set2/set22/set223/set2238/e/): Chell's min mistakes equal `#F` minus the max `+1/-1` subarray sum; GLaDOS DP keeps the smallest Kadane `best` for each `(fakeCount, suffix)` while branching on every `N`.
