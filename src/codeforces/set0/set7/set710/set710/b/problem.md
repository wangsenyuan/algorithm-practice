# 710B — Optimal Point on a Line

Given `n` points on a line, choose an integer coordinate that minimizes the sum of distances to all points. If several coordinates are optimal, output the leftmost one.

Input: `n` (`1 ≤ n ≤ 300000`), followed by `n` coordinates in the range `[-10^9, 10^9]`.
