# C. Blinds（百叶窗）

[题目链接](https://codeforces.com/problemset/problem/38/C)

**标签：** brute force, \*1400

time limit per test: 2 seconds

memory limit per test: 256 megabytes

## 题意

仓库里有 `n` 条宽度为 1 的百叶窗条带，长度分别为 `a_1, a_2, …, a_n`。每条都可以垂直于长度方向切开成若干段（切完后各段长度之和等于原长，宽度仍为 1）。

构造百叶窗时，只能把若干长度相同的段（也可以是未切开的整条原条带）沿长度边依次拼接。若使用 `k` 段、每段长度为 `d`，则得到 `k × d` 的矩形。技术限制：不允许使用长度小于 `l` 的段，即必须满足 `d ≥ l`。

窗口是边长为正整数的矩形。请在遵守上述规则的前提下，求出能完全覆盖的最大窗口面积；若无法得到正面积，输出 `0`。

等价表述：枚举条带高度 `h`（`h ≥ l`），每条原条带 `a_i` 可贡献 `⌊a_i / h⌋` 根高度为 `h` 的条；窗口高为 `h`、宽为条数之和，面积为 `h × 总条数`。求最大面积。

## 约束

- 单组测试（无前导 `t`）
- 第一行：`n l`（`1 ≤ n, l ≤ 100`）
- 第二行：`n` 个整数 `a_i`（`1 ≤ a_i ≤ 100`）

## 输入

第一行两个整数 `n` 和 `l`：条带数量与允许的最短段长。

第二行 `n` 个整数 `a_i`：各条带长度。

## 输出

输出一个整数：最大窗口面积（平方单位）；若无解则输出 `0`。

## 样例

### 样例 1

输入：

```
4 2
1 2 3 4
```

输出：

```
8
```

说明：窗口为 `2 × 4`，用 4 段长度均为 2 的条。其中一段是原长为 2 的整条；一段来自长为 3 的条；两段来自长为 4 的条对半切开。

### 样例 2

输入：

```
5 3
5 5 7 3 1
```

输出：

```
15
```

### 样例 3

输入：

```
2 3
1 2
```

输出：

```
0
```
