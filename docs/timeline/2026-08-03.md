# Learning Timeline — 2026-08-03

- [Codeforces 342C](../../src/codeforces/set0/set3/set340/set342/c/): Side-view packing of radius-`r/2` balloons yields `2⌊h/r⌋` from full layers, then leftover height `x = h mod r` adds 1, 2, or 3 more via the integer tests `2x < r` and `4x² < 3r²` (the √3 threshold for a third balloon under the arc).
- [Codeforces 2237E](../../src/codeforces/set2/set22/set223/set2237/e/): Commutation `b∘a = a∘b` forces each known `b[i]` around its `a`-cycle; after rejecting conflicts and duplicate images, unassigned domain cycles pair with unused equal-length image cycles in discovery order for the lex-smallest completion.
- [Codeforces 2238D](../../src/codeforces/set2/set22/set223/set2238/d/): A good layering of the divisors of `n` needs at least `Ω(n)+ω(n)-1` layers (prime-power chains rise strictly; distinct primes cannot share a GCD>1 chain), and an LPF sieve evaluates that exact minimum per query.
- [Codeforces 2241D](../../src/codeforces/set2/set22/set224/set2241/d/): Alternating `+1/-1` segment ops can freely raise any cell with a length-1 update, so only surpluses matter: a right-to-left scan pushes each excess `a[i]+carry-b[i]` one step left and succeeds iff nothing remains at index 0.
- [Codeforces 2247D1](../../src/codeforces/set2/set22/set224/set2247/d1/): Index swaps with `i⊕j ≤ k` sort an array once values never need to leave aligned blocks of length `2^(h+1)`; after the already-sorted case `0`, try `k = 2^h` in order and take the first block-envelope whose running max stays ≤ the next block min.
- [Codeforces 2247D2](../../src/codeforces/set2/set22/set224/set2247/d2/): The same `f(a)` is a power-of-two segment tree of `(min,max,k)`: merge takes the children’s `k`, and if `left.max > right.min` raises it to the half-width `mid-l`, so each point assignment rebuilds the root answer in `O(log n)`.
