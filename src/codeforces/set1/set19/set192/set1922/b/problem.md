# Forming Triangles

You are given `n` sticks whose lengths are powers of two: the length of stick `i` is `2^a_i`. Count the ways to choose three distinct sticks that can form a non-degenerate triangle.

Each test case consists of `n` and the values `a_1, a_2, ..., a_n`. Output the number of valid choices for each test case.

[Problem link](https://codeforces.com/problemset/problem/1922/B)
